# PhysLens

An Ai-powered educational app where users can upload pictures and see the physics going on, as well as an explanation of what's happening.

**Currently working on: phase 1**

*Disclaimer: this app is for educational purposes, and is meant to be used alongside lessons. It is in no way shape or form meant to replace real teachers. Keep in mind that AI can make mistakes.*

## Phase 1: preliminary app
* basic physics concepts covered (mainly forces and equilibrium)
* only images

## Phase 2: additional features
* videos
* add motion diagrams
