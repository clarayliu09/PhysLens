# PhysLens

What it is: an AI-powered educational app where users can upload pictures and see the physics going on, as well as an explanation of what's happening.

**Currently working on: phase 1**

*Disclaimer: this app is for educational purposes, and is meant to be used alongside lessons. It is in no way shape or form meant to replace real teachers. Keep in mind that AI can make mistakes.*

## Phase 1: preliminary app
* basic physics concepts covered (forces like gravity and normal force)
* only images
* simplest cases (objects resting on each other)

## Phase 2: more complicated cases
* inclines
* hanging objects

## Phase 3: motion
* videos
* add motion diagrams
